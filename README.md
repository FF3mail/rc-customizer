# RC Customizer (GUI)

Лёгкая Windows-утилита на **Tkinter** для удалённой установки и кастомизации страницы входа Roundcube (iRedMail) через SSH/SFTP. Оборачивает Bash-дистрибутив **Full_customize_GROK**.

## Требования

- Windows 10+
- Python 3.10+ (для разработки и сборки)
- Доступ к серверу iRedMail по SSH под **root** (ключ или пароль)

## Запуск из исходников

```bat
cd rc-customizer-gui
pip install -r requirements.txt
python main.py
```

Приложение **не создаёт** файлов конфигурации и **не сохраняет** пароли или passphrase.

## Сборка EXE

```bat
pip install pyinstaller
build.bat
```

Результат: `dist\RCCustomizer.exe` (onefile, windowed). Дистрибутив Bash упакован через `resources/Full_customize_GROK`.

Для разработки включите **«Использовать локальный каталог дистрибутива»** и укажите путь к `Full_customize_GROK/` в корне репозитория.

## Подключение

1. Хост, порт (по умолчанию 22), пользователь `root`.
2. Каталог с приватным ключом (`id_rsa`, `id_ed25519`, `*.pem`, `*.key`) или пароль (альт.).
3. **Подключить** — в журнале появятся отпечатки MD5 и SHA256 host key (политика AutoAdd).
4. Если ключ зашифрован — укажите passphrase (только в памяти до отключения).

При ошибке ключа **пароль не подставляется** автоматически.

## Типовой сценарий

1. Подключиться.
2. **Установить / обновить на сервере** (загрузка в `/tmp/Full_customize_GROK`, `install.sh`, проверка).
3. **Проверка окружения** (`customize_roundcube --test`) — после успеха доступны кастомизация, откат и удаление.
4. **Кастомизация…** — логотип, фон, название, цвета; опционально dry-run.
5. Проверить страницу входа в браузере.
6. **Откат кастомизации** — `customize_roundcube --rollback --yes`.
7. **Удалить с сервера…** — при необходимости откат и удаление бэкапов (`uninstall.sh --yes …`).

## Ручной чек-лист приёмки

- [ ] `python main.py` — окно без создания конфигов в каталоге приложения / `%APPDATA%`.
- [ ] Подключение по ключу (с passphrase и без) — статус «Подключено», отпечатки в журнале.
- [ ] `--test` → Install → Customize (логотип + фон + текст + цвета) → страница входа изменилась.
- [ ] Dry-run не меняет сервер.
- [ ] Rollback возвращает прежний вид.
- [ ] Uninstall с «откат» + «удалить бэкапы» — чистое состояние.
- [ ] **Отключить** / закрытие окна — поля passphrase/пароль пустые.
- [ ] `pytest -q` — зелёный.
- [ ] `dist\RCCustomizer.exe` на чистой машине с bundled distro.

## Тесты

```bat
pip install -r requirements.txt
pytest -q
```

## Безопасность

- Учётные данные только в RAM, очищаются при отключении.
- Удалённые команды собираются как списки аргументов и экранируются через `shlex.quote`.
- SSH/SFTP выполняются только в фоновых потоках; UI обновляется через очередь событий.
